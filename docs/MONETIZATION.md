# Monetization Strategy

- **Freemium Model:** Core game loop is free.
- **In-App Purchases (IAP):** Buy 'PawCoins' to unlock premium accessories or pet types early.
- **Rewarded Video Ads:** Optional ads to double coin rewards post-minigame or revive stat decay.
- **Premium Subscription:** "PawPal Pro" - No ads, exclusive monthly accessories, cloud save sync.
