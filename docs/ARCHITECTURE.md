# PawPal Architecture

- **Frontend:** React + Vite (PWA) using React Router.
- **State Management:** Zustand (`usePetStore`).
- **Styling:** Tailwind CSS + Custom Theme variables (`ThemeContext`).
- **Storage:** LocalStorage (for web) simulating AsyncStorage.
- **Components:** Modular atomic components structured into `ui`, `games`, `shared`, `diary`.
